# catatan-backend

Kumpulan catatan & eksperimen pribadi soal backend Python.

## Fitur

- Script CLI untuk tugas repetitif
- Config terpisah di file YAML
- Logging sederhana ke file
- Unit test dasar (belum lengkap)

## Cara pakai

```bash
git clone https://github.com/umarhandayani3296/catatan-backend.git
cd catatan-backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Contoh menjalankan:

```bash
python main.py
```
